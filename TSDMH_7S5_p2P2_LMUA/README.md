# Práctica 2: Tareas en segundo plano con AsyncTask

Aplicación Android que simula una descarga mediante `AsyncTask`. Permite iniciar o cancelar el proceso y muestra su avance con una barra de progreso, un porcentaje y mensajes de estado.

**Objetivo:** ejecutar una tarea en segundo plano y actualizar la interfaz sin bloquear el hilo principal.
