# Práctica 3: Concurrencia con ExecutorService y Handler

Aplicación Android que simula una tarea en segundo plano con `ExecutorService` y actualiza la interfaz mediante un `Handler` asociado al hilo principal. Incluye seguimiento del progreso, cancelación con `Future` y liberación de recursos al destruir la actividad.

**Objetivo:** gestionar la ejecución, la comunicación con la interfaz y la cancelación de tareas concurrentes.
