# Práctica 1: Componentes de la interfaz de usuario

Aplicación Android en Java y XML para practicar la interacción con botones y listas desplegables (`Spinner`). Utiliza un `ArrayAdapter` para mostrar una lista de frutas y mensajes `Toast` para informar qué opción o botón seleccionó el usuario.

**Objetivo:** reconocer los componentes básicos de la interfaz y responder a sus eventos.
