# Segundo parcial

Prácticas del segundo parcial de TSDMH, grupo 7S5.

Cada carpeta contiene un proyecto independiente de Android Studio. Para trabajar con una práctica, abre su carpeta en Android Studio y sincroniza Gradle.

## Proyectos

- [TSDMH_7S5_p2PRACT1_LMUA](./TSDMH_7S5_p2PRACT1_LMUA/): Componentes fundamentales de la interfaz de usuario en Android (Java y XML con ConstraintLayout).
- [TSDMH_7S5_p2P2_LMUA](./TSDMH_7S5_p2P2_LMUA/): Procesos en segundo plano con AsyncTask y seguimiento del progreso.
- [TSDMH_7S5_P2Practica3_LMUA](./TSDMH_7S5_P2Practica3_LMUA/): Concurrencia y tareas en segundo plano sin bloquear el hilo principal.
- [TSDMH_7S5_p2P4_LMUA](./TSDMH_7S5_p2P4_LMUA/): Navegación dinámica entre pantallas mediante Fragments.

## Historial

Se conservan los commits originales de los cuatro repositorios. Cada proyecto se incorporó en una carpeta con su nombre original. Los repositorios de origen se mantienen intactos.
